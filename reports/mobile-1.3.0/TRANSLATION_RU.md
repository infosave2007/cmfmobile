# Самая маленькая Hy-MT2 на телефоне

**Проверена `hy-mt2-1.8b-q1t.cmf`: 694 894 587 байт, около 695 МБ.**
Это наименьший файл [infosave/Hy-MT2-cmf](https://huggingface.co/infosave/Hy-MT2-cmf).
Скачивание выполнено через каталог приложения, без конвертации и без копирования
с компьютера. SHA-256 скачанного файла на телефоне совпал с Hugging Face:
`aeb52bf287fb52f6e67f452dd72302087420f3b9e2081ed0cb86fd65cf289424`.

## Результат

Xiaomi 2203129G / SM7325 / Android 14, Cortiq Mobile 1.3.0-dev (47),
нативный runtime 0.8.0, **CPU**, GPU выключен. Чат-модель использует генерацию
токенов; это не резонансная Decision-модель. После её загрузки вкладка снова
называется **«Чат»**. Чат и его API не удалены.

В чате телефона получен ответ:

> Доброе утро. Поезд отправляется в 9 часов.

Время интерфейса **4,2 секунды**, 21 выходной токен. Показанные интерфейсом
5,0 ток/с включают подготовку запроса, это не отдельный замер чистого decode.
[Снимок настоящего чата](phone-translation-result.png).

Пять обычных коротких переводов через Wi-Fi API:

| Направление | Полный ответ | Оценка короткого примера |
|---|---:|---|
| RU → EN | 5,02 с | Смысл сохранён, 15:00 передано как 3 PM |
| EN → RU | 6,00 с | Дата, время и просьба принести паспорт сохранены |
| ZH → EN | 3,49 с | Счёт и AB-123 сохранены; «до пятницы» передано как by Friday |
| DE → RU | 5,06 с | Задержка доставки на два дня и неизменный номер сохранены |
| TR → RU | 3,43 с | Встреча завтра в 10:00 передана корректно |

Это ручная смысловая проверка пяти фраз, **не оценка качества всего переводчика**.
Первый запрос холодный, остальные — с загруженной моделью; кэш ответов отсутствует.
Через API использованы `temperature: 0`, `top_p: 1`, `max_tokens: 192`.
Исходные тексты, ответы и времена: [JSON отчёт](hy-mt2-q1t-phone.json).

## Где маленькая модель ошибается

В первом JSON-задании модель перевела добавленную после разделителя инструкцию,
а не JSON. После разделения правил и исходных данных по секциям (по принципу
[рекомендаций Tencent](https://huggingface.co/tencent/Hy-MT2-1.8B)) сохранились
JSON, ключи, число и `{user_name}` / `{order_id}`. Но в немецком тексте модель
придумала неуместное слово **Bestellungsaufenthalt** вместо нормального перевода
«заказ». Формат правильный, перевод — с ошибкой.
[Повтор с исправленным запросом](hy-mt2-q1t-structured-followup.json).

**Вывод:** компактный офлайн-переводчик для коротких обычных фраз работает.
Для автоматического перевода локализаций, JSON, терминологии или важных текстов
нужны проверка результата и более широкая оценка. Малый размер не гарантирует
безошибочное следование сложным инструкциям.

## Память и API

После серии переводов память всего тестового приложения: PSS **1 722 317 КиБ**
(~1,64 ГиБ), RSS **1 812 604 КиБ** (~1,73 ГиБ). Это снимок, не пик и не размер
одних весов. До загрузки приложение предупреждало о малом запасе свободной
памяти; модель всё же загрузилась и все запросы завершились без падения.
Не следует обещать, что файл 695 МБ требует только 695 МБ RAM.

SSE завершался корректным `[DONE]`, но текстовые события приходили одним пакетом
в конце. Поэтому чистая скорость декодирования по промежуткам между сетевыми
событиями **не измерена**. Измеренное полное время ответа достовернее для пользователя.

Дополнительно при погашенном экране (`mWakefulness=Dozing`) API перевёл
турецкую фразу в русский за **4,27 с**. После теста экран включён обратно.
[Результат](hy-mt2-screen-off.json). Это короткая проверка, не гарантия работы всю ночь.

## Как пользоваться

1. **Модели → Hugging Face → Готовые**.
2. Выбрать именно `hy-mt2-1.8b-q1t.cmf` из `infosave/Hy-MT2-cmf`.
3. Загрузить в движок и открыть **Чат**. Для отдельного перевода лучше новый чат.
4. Сообщить целевой язык и отделить исходный текст от инструкции, например:

```text
Translate the following text into Russian. Return only the translation:

Good morning. The train leaves at 9.
```

Сеть нужна для скачивания, не для локального перевода. Через телефонный сервер
используется `/v1/chat/completions`, а не `/v1/decide`. Не добавляйте системное
сообщение без необходимости: у этого семейства собственный встроенный шаблон.
CMF Decision остаётся в библиотеке; её можно загрузить обратно.

Основная магазинная установка 1.2.10 и её данные не менялись. Все проверки
выполнены в отдельном `ai.cortiq.cmf_mobile.dev`.
