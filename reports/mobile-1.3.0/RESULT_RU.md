# Мобильная CMF Decision 1.3.0 — проверка реализации и выпуска

## Что проверено на настоящем телефоне

Xiaomi 2203129G (Android 14, arm64), подключённый по USB.
Тестовая сборка использовала отдельный пакет `ai.cortiq.cmf_mobile.dev`.
Основной `ai.cortiq.cmf_mobile` (1.2.10/46) и его данные не менялись.
После интеграционного теста Flutter удалил временный пакет. Затем для визуальной
проверки установлен свежий APK из GitHub CI (`c415256`, runtime 0.8.0).
На телефоне оставлена отдельная тестовая версия **1.3.0-dev / 47**.

- Нативный runtime 0.8.0, не DemoEngine.
- Полная загрузка CMF с проверками manifest/hash/golden.
- BANKING77 → `card_arrival`; CLINC150 → `weather`; MASSIVE → `play_music`.
- Неизвестный запрос → отказ, `choice: null`.
- Типизированный `/v1/decisions`, удобный `/v1/decide`, discovery навыков.
- HTTP: 401 без ключа, 200 для правильного запроса, 409 для чата с Decision-моделью.
- Оракул через локальный HTTP API включить нельзя.
- Ключ оракула записан и прочитан через защищённое Android-хранилище;
  использован фиктивный тестовый ключ, затем удалён.
- Экран решения отработал без исключений Flutter и показал `card_arrival`.

В трёх smoke-запросах полное нативное решение заняло 21.027, 21.993 и
13.016 мс на CPU. Это **не устойчивый latency-benchmark**. Только резонанс:
4.669, 4.629 и 3.472 мс; кодирование текста измеряется отдельно.
### Визуальная проверка свежего GitHub APK

- Библиотека показывает тип **«Решения»**, назначение модели и кнопку
  **«Открыть решения»**. После загрузки первая вкладка меняется с «Чат» на «Решения».
- Реальный запрос `I still have not received my new card` → `card_arrival`,
  **99,8%**. Десятичный разделитель русский; общее время **27,12 мс** и
  резонанс **6,115 мс** показаны отдельно. Это один smoke-запрос, не benchmark.
- Русский и немецкий экраны оракула проверены на телефоне: подписи помещаются,
  кнопки доступны, настройки по умолчанию выключены, ключ пустой.
- При попытке сохранить `http://example.invalid/v1` показана русская ошибка
  с требованием HTTPS. Никакого обращения к провайдеру не было.
- После проверки восстановлены системный язык (русский), стандартный URL,
  выключенный оракул и пустой ключ. Основное приложение по-прежнему 1.2.10 / 46.

## Остальные проверки

- `flutter analyze`: без замечаний в GitHub CI на коммите `c415256`.
- `flutter test`: **181 passed**, включая семь языков, два размера экрана, масштаб текста 130%, выбор моделей и защиту от параллельной загрузки.
- Rust ABI и настоящий release-CMF на macOS: passed.
- [GitHub CI 36401065516](https://github.com/infosave2007/cmfmobile/actions/runs/36401065516) (`c415256`): анализ, 181 тест, Rust, настоящий CMF, Android и iOS сборки прошли.
  Сборка Apple выполнена в GitHub, не на локальном Mac.
- Android arm64: все ELF LOAD alignment = 0x4000 (16 КБ); Decision ABI экспортирован.
- Реальных платных вызовов MiMo из мобильного приложения не проводили.
  Контракт, ошибки, запрет редиректов, неизвестные метки и отсутствие повторов
  проверены unit-тестами с локальной имитацией HTTP.
