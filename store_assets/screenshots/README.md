# Cortiq Mobile screenshots

`08`, `09`, `11`–`15` are the current **Cortiq Mobile 1.3.0 (47)** public
screenshots captured from the connected iPhone 16 through iPhone Mirroring on
2026-10-01. The app was set to English specifically for the public gallery.

| File | Screen | Notes |
|---|---|---|
| `08_ready_cmf_decision.png` | Ready CMF catalogue | Shows per-file cards and the `Decisions` model type. |
| `09_decision_accepted.png` | Accepted local decision | `card_arrival`, confidence, total and resonance timing. |
| `11_decision_server_redacted.png` | Decision API server | Stopped state; the device-local bearer token is intentionally redacted. |
| `12_oracle_off.png` | Optional Oracle | Manual Oracle is off; no API key is present. |
| `13_companion_current.png` | Companion | Current split-execution safety and transport explanation. |
| `14_settings_oracle.png` | Settings | English language, Oracle’s default-off state, and CPU/GPU behavior. |
| `15_lfm230_iphone_speed.png` | LFM2.5 230M chat | Real iPhone UI with a 162.1 tok/s interactive result; model name and per-message counters are visible. |

These are real device UI captures, not mockups. Do not replace the redacted
server capture with an image containing a LAN address, QR code, bearer token,
API key, or personal conversation.
