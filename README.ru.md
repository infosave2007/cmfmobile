# CMF Mobile

**Запускайте локальные AI-модели на телефоне. Раздавайте их в сеть. Конвертируйте прямо с Hugging Face.**

[![Flutter](https://img.shields.io/badge/Flutter-3.44-02569B?logo=flutter)](https://flutter.dev)
[![Platforms](https://img.shields.io/badge/платформы-Android%20%7C%20iOS-brightgreen)]()
[![License](https://img.shields.io/badge/лицензия-Apache--2.0-blue)](LICENSE)
[![Protocol](https://img.shields.io/badge/CMF-v2-00d4aa)](https://github.com/infosave2007/cmf)

CMF Mobile — мобильная часть экосистемы [CMF](https://github.com/infosave2007/cmf)
(Cortiq Model Format): Flutter-приложение, которое превращает Android- или
iOS-устройство в полностью локальную AI-станцию — чат, библиотека моделей,
встроенный конвертер с Hugging Face и OpenAI-совместимый сервер по протоколу CMF.

*See also: [README.md](README.md) — documentation in English.*

## Возможности

### 💬 Чат
- Стриминг ответов со **статистикой по токенам на каждое сообщение**: время, токены промпта/ответа, ток/с
- **Темы с сохранённым контекстом** — каждый диалог хранится и продолжается, как в GPT-приложениях
- **Вложения документов** (txt/md/код/json/…) — встраиваются в промпт, если модель позволяет
- Markdown, копирование, повторная генерация, стоп
- **Отключение размышлений** — модели с рассуждением (Qwen3/3.5) отвечают сразу, без блока `<think>`

### 📦 Модели
- Локальная библиотека `.cmf` с метаданными: архитектура, квантизация, слои, контекст, маски задач
- **Проверка оперативной памяти** перед загрузкой — предупреждение вместо OOM-убийства
- Загрузка/**выгрузка** модели в одно касание (освобождает память и батарею)
- Импорт `.cmf` из хранилища устройства

### ⬇️ Конвертер с Hugging Face (как в cortiq-gateway, но на телефоне)
- Поиск по хабу, выбор модели и квантизации, живой прогресс
- **Многопоточная конвертация на устройстве** safetensors-репозиториев в CMF v2
  (энкодеры бит-в-бит с эталоном, пул изолятов по настройке «Потоки CPU»):
  - архитектуры dense Qwen3.5 GatedDeltaNet и Gemma 1/3/4
  - `Q8_2F` — 8 бит, два поля (𝒲×θ), рекомендуемый баланс качество/размер
  - `Q8_ROW` — 8 бит на строку
  - `Q1T` — **тернарное без обучения** ({−s, 0, +s}, ~2,25–3 бита, ниже q4)
    с построчным f16-оверлеем выбросов; самая компактная рабочая конвертация на устройстве
  - `Q1` — **1,5 бита для 1-битно обученных моделей** (Bonsai/BitNet: 27B-модель — ~5 ГБ)
  - `F16` — без квантизации
- **Рекомендуемые модели** закреплены сверху — готовые `.cmf` качаются в один тап
  (включая мобильную
  [infosave/Bonsai-1.7Bcmf](https://huggingface.co/infosave/Bonsai-1.7Bcmf)
  и [infosave/Bonsai-27Bcmf](https://huggingface.co/infosave/Bonsai-27Bcmf))
- Репозитории с готовыми `.cmf` скачиваются напрямую — любая квантизация
- На устройстве конвертируются канонические Qwen MoE и LFM2-MoE/ShortConv,
  включая отдельные файлы шаблонов чата
- **Устойчивые загрузки** — параллельные byte-range-скачивания переживают
  многоминутные обрывы мобильной сети / DNS (`Failed host lookup`, сбросы, TLS,
  таймауты): повтор в течение 5-минутного окна без прогресса с ограниченным
  backoff, **продолжение с последнего записанного байта** и разрыв «мёртвого»
  сокета по 30-секундному таймауту простоя — вместо обрыва многогигабайтной
  загрузки из-за короткого сбоя
- Очередь задач с фазами, логами и отменой — тот же flow, что в gateway

### 📡 Сервер
- Телефон становится **сервером протокола CMF** (OpenAI-совместимым):
  `POST /v1/chat/completions` (JSON + SSE), `POST /v1/completions`,
  `GET /v1/models`, `GET /v1/cortiq/status`, `GET /v1/cortiq/masks`,
  `POST /v1/cortiq/switch`, `GET /healthz`
- QR-код с адресом, список LAN-адресов, лог запросов, живые счётчики
- Опциональная авторизация **Bearer-токеном**
- Экран не гаснет, пока сервер работает

### 🌍 Локализация
Семь языков, как в cortiq-gateway: **English, Русский, Deutsch, Français, Español, 中文, Türkçe**.

## Быстрый старт

```bash
flutter pub get
flutter gen-l10n
flutter run
```

**Приложение идёт с настоящим рантаймом cortiq** —
`libcortiq_ffi` v0.4.1 (arm64-v8a, armeabi-v7a, x86_64 + статическая библиотека iOS) из [релизов cmf](https://github.com/infosave2007/cmf/releases)
вшит в `android/app/src/main/jniLibs/`, так что чат и сервер выполняют
реальный инференс на устройстве из коробки (проверено end-to-end:
qwen3-5-4b Q8_2F стримит через этот же биндинг — см. `tool/ffi_smoke.dart`).
Статическая библиотека iOS линкуется через `ios/Flutter/Cortiq.xcconfig`.
Там, где библиотеки нет, приложение переключается на честно подписанный
**демо-движок**; детали — в [native/README.md](native/README.md).

## Релизы

Пуш тега `v*` автоматически собирает release-APK (universal + per-ABI) и
неподписанный iOS-архив и прикладывает их к GitHub Release
(см. [.github/workflows/release.yml](.github/workflows/release.yml)).
